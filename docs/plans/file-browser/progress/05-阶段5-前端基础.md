## 实施期发现

- ConsolePage 是早期单实例时代页面,生产实际用的是 `MultiInstanceConsole`。所有 modal 走 modal-stack `present(args)` presenter 模式。新增 sheet 接入需写 `useFileBrowserPresenter` 而非直接 useState — 与 share/settings/createInstance 一致。
- broker `tsc -b` 增量编译有缓存陷阱:**新增 import 不会触发已编译模块重 emit**,导致 dist 缺 broker-server.js 等关键产物。解决:`rm -rf backend/dist backend/tsconfig.tsbuildinfo` 后 `pnpm build` 全量重出。后续若改 `shared/src` 也需要同样清缓存。
