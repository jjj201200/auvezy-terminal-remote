## 实施期发现

- `EventSource` 在 React effect 中:必须把 handle 放 ref(`useRef<SearchHandle>`),否则 setState 触发 re-render 时旧 handle 丢失,cleanup 来不及 cancel,导致服务端流泄漏。
- SearchResults 占据整个 `.body` 宽度时,grid 子项 grid-column 设 `1 / -1` 覆盖父 `300px 1fr` 列定义,这是简单做法;移动单栏不受影响。
