## 实施期发现

- Shiki 4.x 顶级 `codeToHtml(code, { lang, theme })` 是最简单的 API,内部 singleton + lazy 都搞定。**不需要**自己写 `getSingletonHighlighter` + `loadLanguage`(plan.md 中的伪代码已被 ADR-006 实际版本覆盖)。
- Shiki 输出 `<pre class="shiki">` 自带 background / color 内联样式(走 theme);scss 容器只需让它自由发挥,padding 加在内 pre 上;`.textPre` 从 `<pre>` 改 `<div>`,内部样式用 `:global(pre.shiki)` 选择器穿透 CSS Modules。
- vite 自动拆 chunk 不需要 `manualChunks` 配置。dynamic import 即可。
